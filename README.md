# DEP Energy Project

Data exploration and preparation project examining how countries’ electricity mixes changed from 2000 to 2023, and how those patterns relate to carbon intensity, energy use, and geography. The analysis includes data cleaning, exploratory visualisations, categorical encoding, and principal component analysis.

## Run the analysis

Open `DEP_Energy_Project.Rproj` in RStudio, then open `energy_analysis.R` and run it. The script reads the CSV files from `data/`. It requires the R packages `tidyverse`, `countrycode`, `gridExtra`, and `scales`.

## Data

The raw energy dataset is from [Our World in Data](https://github.com/owid/energy-data) and is licensed under CC BY 4.0. The cleaned dataset is generated by the analysis script.
